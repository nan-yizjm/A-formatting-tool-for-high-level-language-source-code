# C语言源程序分析与格式化工具

本项目使用手写词法分析器、递归下降语法分析器和抽象语法树（AST）处理课程要求的C语言子集。格式化结果由AST重新生成，不是对原文件逐行添加缩进。

## 编译与运行

在项目根目录打开PowerShell：

```powershell
.\build.ps1
.\实验源程序\formatter.exe
```

程序支持直接输入路径，也支持把源文件拖入终端。路径含空格、中文或被双引号包围均可使用。格式化结果保存在输入文件旁，名称为“原文件名`_formatted.c`”。

## 菜单功能

1. 词法分析：显示Token类别、原文和行列位置，并报告非法数字、未闭合字符串或注释等错误。
2. 语法分析：显示完整AST，包括声明、函数、控制语句、表达式、函数调用和数组访问。
3. 格式化输出：按每层4个空格从AST生成新C文件。
4. 格式化预览：不写文件，直接在终端查看结果。
5. 重新选择文件：保持程序运行并切换输入文件。

## 支持范围

- 预处理行：如`#include`、`#define`，按原文保留。
- 注释：行注释、块注释以及字符串中的注释符号。
- 声明：常见基本类型、类型修饰符、多个声明符、一维或多维数组、表达式初始化。
- 函数：声明、定义、参数、调用、字符串实参和数组实参。
- 语句：复合语句、表达式语句、`if/else`、`while`、`for`、`return`、`break`、`continue`和空语句。
- 表达式：赋值、逻辑、关系、加减乘除取模、一元正负号与逻辑非，并按C语言优先级建树。

指针、结构体成员、`switch`、`do/while`、位运算、自增自减和复杂初始化列表不属于本课程工具当前实现的C语言子集。词法分析器仍能把C关键字识别为关键字，但语法分析会明确拒绝超出子集的结构。

## 自动检查

```powershell
.\run_tests.ps1
```

测试会重新编译项目，检查正确与错误输入、格式化后二次解析、关键AST节点，并用真实的C编译器对综合格式化结果执行语法检查。人工演示可使用[valid_complete.c](测试用例/valid_complete.c)。

## 源码结构

- `main.cpp`、`console_ui.h`：文件操作、错误上下文、Token表格和终端菜单。
- `source_lexer.*`：DFA式扫描和Token生成。
- `ast.h`、`source_parser.*`：AST数据结构及递归下降语法分析。
- `source_formatter.*`：遍历AST并生成统一格式的C代码。

项目只保留上述新版源码，不包含旧解析器或旧格式化实现。
